# BurnCorder
Utility for straight-to-CD live shows recroding and Enchanced CD burning in general

## Setup guide
Clone the repo to your working diary.
Run the usr_setup.py script to create a default config file.
Ech time you move the repo folder delete the config file and run the usr_setup.py script.
